# Binning 120 FPS 曝光調整（2026-10-07）

已將持續串流的左右眼曝光由 256 行改為 1000 行，類比增益保持 `0x0320`，AE 關閉。以 VTS=1350、實測 120 FPS 推算：每行約 6.17 μs，256 行約 1.58 ms，1000 行約 6.17 ms。這是時序估算，未以示波器量測曝光起訖；長曝光的移動模糊尚未實測。

| 左右眼中央 80% 區域的解碼影像取樣 | 256 行 | 512 行 | 1000 行 |
|---|---:|---:|---:|
| 曝光估算 / ms | 1.58 | 3.16 | 6.17 |
| 解碼 PTS FPS | 119.996 | 120.000 | 120.000 |
| 8-bit 灰階均值 | 6.40 | 10.82 | 20.88 |
| 8-bit 灰階中位數 | 0 | 0 | 7 |
| 接近黑色（<=5）比例 | 92.3% | 77.4% | 34.5% |
| 接近白色（>=250）比例 | 0.99% | 1.69% | 2.63% |

亮度統計取每組第 31 張軟體解碼 RGB 影像的左右眼中央區域，每四個像素取樣，共 27904 點；場景未以實驗室光源控制。本次平均亮度約增加 3.26 倍，暗部輪廓改善，窗戶亮部更容易飽和。不能把影像平均值直接當作感測器感光度。未加 gamma、顯示增益或影像增亮處理。

20 秒複測收到 2396 張解碼影格、2396 個不同 RGB hash，PTS FPS 119.9975，實際左右眼場景已檢視。長時間配對偶有丟幀的限制仍存在。

曝光透過 V4L2 exposure control 調整，讀回左右感測器 `3e00/01/02=00/3e/80`，確認硬體為 1000 行。HTS/VTS 不變。`set-binning-exposure.sh` 依 I2C sensor 身分尋找 subdevice，限制在已運行的 120 FPS binning 模式，檢查 VTS 安全範圍並讀回實際值。為避免驅動快取值相同而略過硬體更新，先寫入相鄰合法值，再寫入目標。

RTSP 啟動器預設 `EXPOSURE_ROWS=1000`，在两眼 receiver 已啟動後設定曝光。重啟相同 binning 服務會套用此曝光；板子重開機仍需原先的一次載入實驗流程。沒有替換已安裝的 kernel module。

同次開機手動調整：

```sh
sudo bash /home/ubuntu/sc132gs-binning-20261007/set-binning-exposure.sh 1000
```

要測原短曝光可改為 `256`。不要啟用舊 AE 或直接改動 binning 參數；此實驗時序尚未整合回原 AE 的行時鐘模型。
