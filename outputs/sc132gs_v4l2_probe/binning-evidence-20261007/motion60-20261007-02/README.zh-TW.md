# Binning 60 FPS 揮手測試

2026-10-07，維持既有半解析度雙目 RTSP 設定，曝光約 14.8 ms。

- RTSP 錄影：motion.mkv，1088×640，H.265，容器標示 60/1 FPS，長度 25.067 秒。
- 保留 501 張軟體解碼 RGB 圖像，每 3 個解碼 frame 擷取一張。
- 原錄影程式等待 EOS 時逾時；影片經 gst-discoverer 確認可 seek，再透過 matroskademux / h265parse / avdec_h265 完整解碼至 EOS，exit 0。
- 這次未留下完整逐幀 PTS 統計，不能將容器 60/1 當成本次實測 FPS。
- 兩眼均錄到揮手。frame-1008.png 的輪廓較清楚；frame-1104.png 的手指邊緣有明顯模糊，靜態背景相對清楚。
- 手部呈暗色剪影，亮窗過曝。可用於觀察大輪廓；未驗證偵測模型、細線辨識或高速避障性能。
- 沒有受控物體速度、距離或確定靜止的手部參考，所以不報告模糊像素寬度或速度門檻。

motion-comparison.jpg 是兩張完整解碼畫面的比較，未調整亮度。
