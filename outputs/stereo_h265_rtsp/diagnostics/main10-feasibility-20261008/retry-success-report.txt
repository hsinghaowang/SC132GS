Driver source reference:
Nearby Ubuntu source version 6.8.0-1079.84 diff was inspected (not exact
running 1084 source). QCM6490 capabilities include HEVC P010 and TP10C.
Media layout helpers specify P010 byte stride align(width*2,256),
pixel stride align(width,128), Y scanlines align(height,32).
At tested dimensions these match the driver-returned layouts.
GStreamer 1.24.2 upstream V4L2 object source lacks P010 mapping:
https://raw.githubusercontent.com/GStreamer/gstreamer/1.24.2/subprojects/gst-plugins-good/sys/v4l2/gstv4l2object.c
Current installed factory rejects P010 before linking; native V4L2 bypasses
this limitation. Camera RTSP application still uses original NV12.
